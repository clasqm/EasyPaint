EasyPaint
=========

EasyPaint is a simple graphics painting program

[![easypaint.png](https://i.postimg.cc/R02Q7hnM/easypaint.png)](https://postimg.cc/gwqZdYD5)

This version of Easypaint was converted from QT4 to QT5 dependencies with special attention to being compilable under the Haiku Operating System. It may need further refinement with other operating systems.

Installing
----------

Install EasyPaint using the following commands:

    cd ./EasyPaint
    cmake -DCMAKE_INSTALL_PREFIX=/usr
    make
    make install
